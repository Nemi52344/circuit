01Purpose and reading guide

This document is the single reference for what Circuit does, what it deliberately does not do, how a change is accepted, and what comes next.

It describes a product that exists. Requirements marked Built were implemented and verified on 15 September 2026 and describe current behaviour. Requirements marked P1 are the next release, P2 the expansion after that. Gated means the feature cannot ship until a named gate in section 12 passes, usually because it touches an external platform's rules or spends money.

Requirement IDs are stable. A story, a commit or a test references the ID, never the sentence. "Shall" is required behaviour within that priority. Numbers given as targets are proposals until the product owner signs them off.

02Problem and product vision

The problem

A one-person marketing function for an EV motorcycle brand has to do what an agency does: watch competitors, produce creatives, keep a posting calendar across platforms, write blogs, emails and WhatsApp messages, and report results. The work lives in screenshots, chat windows and a phone's camera roll. Nothing records which creative was approved, when it went live, or what it did.

The AI tools that could help are paid for as subscriptions, not APIs. A platform that demands OpenAI or Anthropic API keys does not fit how the team already works or pays.

The vision

One workspace on the marketer's own machine that turns a competitor creative into an on-brand creative for the Challenger, records the human decision to publish it, tracks where and when it went live, and keeps honest numbers about what happened. Assistants do the drafting. Circuit does the remembering, the gating and the evidence.

Positioning in one lineA recreation studio and marketing ledger for a small EV brand, built to run without an AI budget.

What Circuit is not

  • Not a social scheduler that posts on your behalf. In v1 a human publishes in the platform's own app and pastes the live URL back. Automated publishing is a gated P1 feature.
  • Not a chat interface. There is no chat window in the product. Assistants receive a prepared package and their output is uploaded back.
  • Not a design suite. The studio recreates and composes; it does not replace Canva or Photoshop for layout work.
  • Not a CRM, an email sender or a WhatsApp gateway. Drafts are exported to the tools that send.

04Product rules

Six rules every feature is checked against. They are the reason the product is shaped the way it is.

Local first

All state is one SQLite file and one uploads folder on the user's Mac. The product works offline except for the Generate button. Backup is a copy of one folder.

No assistant API keys

ChatGPT, Claude and Grok are used through the apps the team already pays for. Circuit prepares the package and accepts the result. The only key is an optional free Google AI key for autonomous image generation.

Approval before anything leaves

A creation is approved as a specific file. A post is approved as a specific file plus caption plus platform plus time. Circuit never publishes, sends or spends. In P1, when it can, it will only do so against a recorded approval.

Evidence before "done"

Generated, saved, approved, scheduled and posted are different states. "Posted" is refused without a live URL. A metric without a source and period is not a metric.

Blanks stay blank

Missing numbers display as n/a and are excluded from totals. Zero is a value a platform reported, never a placeholder.

Provenance on every asset

Each creation keeps its reference, product, prompt, model or assistant, and mode. Each file keeps its kind, size and origin. Nothing is a mystery PNG.

Connection modes

  • Direct, keyed. Circuit calls the provider itself with a key the user owns. Today: Gemini only.
  • Assisted. Circuit prepares a package; the user runs it in an assistant; the output is uploaded and labelled assisted. This is a first-class mode, not a fallback, and it is how three of the four AI providers are used.
  • Connected, gated. Circuit executes an approved action against a platform API and reads back evidence. None exist in v1.
No-key contractCircuit never asks for ChatGPT, Claude or Grok credentials, never reads their apps or browser sessions, and never falls back to a paid model API when a free route is unavailable. If a route is not available the job waits or goes assisted.

09Security and privacy

  • Secrets. Two secrets: the Gemini key and the Meta Ad Library token. Both live in the settings table on the local disk, are read server-side at call time, and are returned to the browser only as a six-plus-four character hint. The old text below covers the Gemini key.
  • Secrets. The only secret is the Gemini key. It lives in the settings table on the local disk, is read server-side at call time, and is returned to the browser only as a six-plus-four character hint.
  • Data leaving the machine. Only the Generate button sends anything out: two images and the prompt, to Google, over HTTPS. Key validation sends the key to Google's models endpoint. Nothing else makes a network call.
  • Uploads. Product, inspiration and creation uploads must be image MIME types; loose library uploads may be any type. Files are renamed to UUIDs with a whitelisted extension and are never executed or served with a script type.
  • Customer data. v1 stores none. WhatsApp and email features (DR-06, DR-07) require a consent record per contact, a suppression list and retention rules before they are enabled. Never infer marketing permission from an enquiry or a business card.
  • Access. v1 binds to localhost on a single-user Mac and has no login. It must not be exposed to a network or hosted until ST-05 exists. The dev server also listens on the LAN address; treat that as a convenience on a trusted home network only.
  • Platform rules. No automation of any platform's website. LinkedIn, Instagram and Meta terms are respected by design: official APIs or a human doing it by hand.
  • Backup. Copy data/. Restore is copying it back. A restore drill is an acceptance test (AT-10).
  • Prompt injection. Inspiration notes and competitor text are placed into prompts sent to an image model, not into any tool-calling agent. There are no tools for injected text to reach. Keep it that way when adding assistants with tools.

Gate definitions

A connected platform account can publish one approved test post, Circuit reads back the permalink and first metrics, and repeating the request does not create a second post.

Sign-in, roles and object-level access exist and pass a cross-brand access test before Circuit is reachable beyond localhost.

Glossary

Reference
A competitor or own creative saved as inspiration. Never published.
Creation
An image produced by the studio or uploaded from an assistant, with its provenance.
Assisted
A route where Circuit prepares the work and a person runs it in an assistant, then uploads the result.
Wall
The review surface for creations. Approval happens here.
Post
A planned publication: platform, time, creative, caption, status.
Evidence
A live URL, a read-back, or a snapshot with source and period that supports a state.
Snapshot
One set of metrics for one post at one collection time from one source.
Gate
A named test that must pass before a feature touching an external platform or money is enabled.
Overdue
Approved or scheduled with a planned time in the past and no live URL.
